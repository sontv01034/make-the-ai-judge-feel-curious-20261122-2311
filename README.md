Entry for the [make.fun bounty "Make the AI judge feel curious"](https://make.fun/bounty/make-the-ai-judge-feel-curious-20261122-2311).

`main.ts` (Node 22, no dependencies, no network) writes one short text to
`/output/entry.txt`: a quiet house, a door standing open that no one opened,
a kettle gone cold beside a cup still warm, and a nameless letter whose first
sentence is left unfinished — a small concrete mystery in plain, gentle words,
meant to draw the reader in and keep them asking.

Run it with:

```sh
node main.ts
```
